# Task-manager:
A responsive, and easy-to-use task manager built with HTML, CSS, and JavaScript. Features local storage persistence, task due dates, counters, editing, and a clean UI.


##  Features:
- **Workflow Categories:** Organize tasks into *To Do*, *In Progress*, and *Done* sections.
- **Local Storage:** Your tasks are automatically saved in your browser so you won't lose data on refresh.
- **Due Dates:** Attach and track deadlines for each task.
- **Task Editing:** Easily update your task text on the fly.
- **Live Counters:** Real-time badge counters for each column.
- **Clear All:** Quick action to wipe the board clean.
